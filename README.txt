FILES

- style.css: layout, colors, responsive design
- script.js: interactive superpower reveal and current year

HOW TO RUN
1. Extract this ZIP into a folder.
2. Open the folder in VS Code.
3. Open index.html in your browser (or use the Live Server extension).
4. Edit the contact details and check every project description before publishing.

IMPORTANT PERSONALIZATION
- Replace the email, LinkedIn and GitHub placeholders in index.html.
- Update project descriptions to reflect the real features and current status.
- Add only skills you can honestly discuss.
- This is a static front-end starter; AWS deployment and any backend/database are separate next steps.
